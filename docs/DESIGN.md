# 3인 비동기 당구 게임 — 기획 초안 v0.10

> 상태: 초안 (결정 필요 항목은 `❓` 표시)

## 0. 핵심 콘셉트
- 3명(A·B·C)이 **각자 시간 날 때 접속해서 자기 턴만 치고 나가는** 비동기 턴제 당구.
- 모든 샷은 **기록(로그)으로 남고**, 나중에 접속한 사람은 **리플레이 + 요약**으로 따라잡는다.
- 채팅은 게임 기록과 같은 타임라인에 섞여 보인다 (샷 이벤트 ↔ 대화).

## 1. 게임 흐름
| 단계 | 내용 | 비동기 처리 |
|---|---|---|
| ① 순서 정하기 (뱅킹) | 각자 공 1개를 쳐서 반대편 쿠션 맞고 돌아와 **내 쪽 쿠션에 가장 가깝게** 세우기 | 3명이 **동시에 각자** 1샷. 3명 다 치면 결과 공개 (먼저 친 사람 결과는 숨김) |
| ② 메인 경기 (4구 가정 ❓) | 득점하면 계속 침, 실패 시 다음 사람 | 한 번 접속에 **내 턴(연속 샷) 전체**를 끝내고 나감 |
| ③ 마무리 쿠션 | 목표 점수 도달자는 **쓰리쿠션 성공**해야 승리 확정 | 메인과 동일한 턴 구조, 화면에 "마무리" 상태 표시 |
| ④ 정산 | 순위·통계·게임비/내기 정산 ❓ | 3명 모두 "확인" 누르면 게임 종료 처리 |

## 2. 비동기 운영 규칙
- **턴 알림**: 내 차례가 되면 알림 (방법 ❓: 앱 푸시 / 이메일 / 매크로드로이드 폴링).
- **턴 제한시간**: 기본 24시간 (❓). 초과 시 1차 리마인드 → 2차는 자동 패스 or 대기 유지 (설정).
- **중간 이탈 안전**: 샷 1개 단위로 즉시 서버 저장. 턴 도중 앱 꺼져도 이어서 칠 수 있음.
- **샷 되돌리기 없음**: 손 미끄러짐 방지를 위해 발사 전 "조준 확정" 단계 1회.
- 동시 진행: 같은 3명이 **여러 판을 병렬로** 진행 가능 (❓ 1판만 할지).

## 3. 캐치업(따라잡기) 화면
접속 시 첫 화면 = **"내가 없던 동안"** 카드
- 예) `B: 3연속 득점(+30) 후 실패 · C: 1샷 실패 · 새 채팅 7개`
- [리플레이 보기] 1x / 2x / 4x, 샷 단위 건너뛰기
- 현재 점수판, 남은 점수, 누가 마무리 단계인지
- 미확인 채팅으로 바로 점프

## 4. 채팅
- 가로 화면 기준 **테이블 오른쪽 접이식 패널** (세로 모드면 하단 시트).
- 시스템 메시지 자동 삽입: `[B 득점 +10]`, `[C 턴 시작]` → 대화 맥락 유지.
- 메시지에 "몇 번째 샷" 태그 → 탭하면 해당 샷 리플레이.
- 이모지/짧은 반응(👍 ㅋㅋ 😱) 원탭 버튼.

## 5. 샷 조작 (모바일)
- 드래그로 조준 방향, 하단 파워 게이지, 큐볼 당점(회전) 패드, 가이드라인(1쿠션까지 예측선 등 난이도 옵션 ❓).
- 물리: 2D 탑뷰, 공-공 충돌·쿠션 반사·회전(당점)·마찰.

## 6. 기술 구조 (제안)
- **클라이언트**: HTML5 Canvas + JS 웹앱(PWA) → 안드로이드 크롬에서 "홈 화면에 추가"로 앱처럼 사용. 별도 설치 불필요.
- **호스팅**: GitHub Pages (무료).
- **서버/DB**: Google Apps Script 웹앱 + Google Sheets (게임상태·샷로그·채팅 시트) — 실시간성 필요 없음, 무료.
  - 대안: Firebase (푸시 알림이 쉬움, 설정 조금 더 필요).
- **결정론적 기록**: 샷 입력값(방향·파워·당점) + **샷 결과 공 위치**를 함께 저장 → 기기마다 물리 오차가 달라도 기록이 기준.
- **알림**: GAS가 턴 변경 시 이메일 발송, 또는 매크로드로이드가 주기적으로 GAS 조회 → 내 턴이면 폰 알림.

## 7. 데이터 모델 (초안)
- `games`: id, 참가자, 목표점수(개인별), 상태(ordering/main/finish/settle/done), 현재턴, 공 위치
- `shots`: game_id, seq, player, 입력값, 결과 위치, 득점여부, 시각
- `chat`: game_id, seq, player, 내용, 연결된 shot_seq, 시각
- `reads`: player별 마지막으로 본 shot/chat seq (캐치업 계산용)

### 3쿠션 3인 규칙 (제안)
- 공 3개: **흰색 · 주황색 · 빨간색** (확정)
- **수구는 모든 플레이어가 항상 흰 공** (확정). 적구는 늘 주황·빨강
- 공 배치는 이전 사람이 끝낸 상태 그대로 이어받음 → 실패 시 다음 사람에게 어려운 배치를 남기는 수비 전략이 생김
- 득점: 수구가 두 적구를 모두 맞히고, **제2적구 맞기 전 쿠션 3회 이상**.
- 득점하면 계속, 실패하면 다음 사람. 공 위치는 그대로 이어감.

### "마지막 쿠션 세션" (❓ 해석 확인 필요)
- 제안: 누군가 목표점수 도달 → **나머지 2명에게 마지막 1이닝(역전/동점 찬스)** 부여. 이닝 공평 원칙.
- 이 마지막 이닝은 연출을 따로 (긴장감 BGM, 채팅에 "C의 마지막 기회" 시스템 메시지).

### 정산 = 세리머니 & 조롱 타임
- 가상 포인트: 1위 +, 3위 − (배분 규칙 ❓). 누적 리그 순위표.
- 자동 생성 카드: **오늘의 명장면**(최다 쿠션 득점), **오늘의 삽질**(가장 아깝게 놓친 샷 / 공을 하나도 못 맞힌 샷), 하이런, 이닝당 평균(애버리지).
- 꼴찌에게 다음 경기까지 붙는 **칭호/배지** (예: "쿠션 기부천사").
- 명장면·삽질 샷은 **리플레이 링크**로 단톡방 공유.

### 재촉 기능
- 차례가 아닌 사람이 "재촉" 버튼 → 해당 사람에게 카톡 알림. 남용 방지로 사람당 6시간에 1회.

### 카카오톡 알림 구현 방안
1. **(권장) 카카오 로그인 + "나에게 보내기" API**: 각자 웹에서 카카오 로그인 1회(동의 체크) → 서버(GAS)가 그 사람의 "나와의 채팅"으로 "당신 차례입니다 [링크]" 전송. 설치 없음, 무료, 심사 불필요.
   - 로그인 자체가 본인 식별이 되므로 별도 회원가입 불필요.
   - 리스크: 나와의 채팅 알림이 꺼져 있는 사람이 있음 → 첫 로그인 때 안내 1줄.
2. 제작자 폰 매크로드로이드가 3인 단톡방에 자동 메시지 (제작자 폰이 항상 켜져 있어야 함, 불안정) — 보조용.
3. 카카오 알림톡(비즈 채널) — 사업자 필요, 유료 → 제외.

### 접속 흐름 (B·C 입장)
1. 단톡방/카톡 알림의 링크 탭 → (카톡 인앱 브라우저에서 바로 열림)
2. 최초 1회 카카오 로그인 → 이후 자동
3. "내가 없던 동안" 요약 → 리플레이 → 내 샷 → 닫기

### 프로토타입
- `prototype/practice.html`: 1인 연습장. 물리 엔진(슬라이딩/구름, 당점 회전, 쿠션 회전 효과), 3쿠션 득점 판정, 조준/당점/힘 조작, 가로·세로 화면 대응.

## v0.3 추가 기획 (2026-11-15)

> 진행 원칙: 기획 확정 전까지 코딩 중단. 제작자가 "코딩 시작" 지시할 때 착수.

### A. 화면 구조의 중심 = "샷 피드"
게임에 계속 붙어있지 않으므로, 메인 화면은 실시간 당구대가 아니라 **샷 단위 피드(타임라인)**.
- 피드의 한 단위 = **[선언 카드] → [결과 카드(리플레이)] → 그 샷에 달린 채팅/반응**
- 접속하면 "마지막으로 본 지점"부터 피드가 이어짐 → 자연스러운 캐치업
- 당구대 화면은 (1) 내 차례에 칠 때 (2) 리플레이 볼 때 열림

### B. 샷 선언 (공 치기 전 의도 공개)
**흐름**: 내 차례 → 테이블 보며 구상 → **선언 작성 → 공개** → (갑론을박) → 실제 샷
- 선언 내용
  1. **예상 경로 그리기**: 수구 출발 → 쿠션 지점들을 차례로 탭 → 꺾은선 경로 (제1적구·제2적구 지정)
  2. **샷 종류 태그**: 뒤돌리기 / 옆돌리기 / 앞돌리기 / 빗겨치기 / 대회전 / 더블레일 / 리버스 등
  3. **한마디**: "이건 눈 감고도 들어간다" 같은 도발 (선택)
  4. (선택) **자신감** 또는 가상포인트 걸기
- **공개되지 않는 것**: 실제 조준각·힘·당점 (샷 후 리플레이에서 공개)
- 다른 참여자 반응
  - 선언 카드에 채팅/댓글
  - 원탭 예측: **"된다 / 안 된다"** (+선택적으로 가상포인트 내기) → 결과 나오면 자동 정산
- 결과 판정 (실제 궤적 vs 선언 경로 비교)
  - 선언대로 득점 → **선언 성공** (보너스 ❓)
  - 득점했지만 경로가 다름 → **"뽀록"** 딱지 (득점은 인정, 조롱 소재로 기록)
  - 실패 → 선언 카드에 "실패" 도장, 예측 정산

### C. 리플레이
- 기록 방식: 샷 입력값 + **전체 공 궤적(키프레임)** 저장 → 어느 폰에서 봐도 똑같이 재생
- 플레이어 기능
  - 재생/일시정지/**무한 반복**, 속도 0.25x · 0.5x · 1x · 2x
  - **타임라인 스크럽** + 이벤트 마커 (쿠션①②③, 제1/제2적구 접촉) → 마커 탭으로 해당 순간 이동
  - **선언 경로 겹쳐보기** (선언 vs 실제 비교 — 뽀록 감상용)
  - 궤적 잔상, 공별 경로 색 구분
  - 실제 당점·힘·조준 공개 패널
- **타임코드 채팅**: 리플레이 특정 순간에 댓글 ("2.3초 이 쿠션에서 이미 틀렸음") → 탭하면 그 순간으로 이동
- 모든 과거 샷은 경기 끝난 뒤에도 다시 볼 수 있음 (정산 타임의 "명장면/삽질" 소스)

### D. 긴 간격 턴 운영
- 한 사람의 이닝 = 선언→샷 반복 (득점 시 계속). 이닝 도중 나가도 그대로 보존, 제한시간 없음
- 상태 표시: `B 차례 · 선언 대기중 (14시간째)` / `B 선언 완료 · 샷 대기중`
- 카톡 알림 종류 (각자 켜고 끄기)
  - 내 차례 (필수)
  - 누가 선언했음 → 갑론을박 참여 유도
  - 샷 결과 나옴 (리플레이 링크)
  - 내 선언/샷에 댓글
  - 묶음 알림 옵션: "알림 너무 많으면 하루 2번 요약"

## v0.4 결정/추가 (2026-11-15)

### 선언 규칙 확정
- 선언은 **선택 사항**. 선언하면 이득이 있음 (아래 후보 중 결정 ❓)
- 선언 후 **즉시 칠 수 있음**. 의견을 기다릴지 말지는 치는 사람 마음
- 선언 성공 판정 기준(제안): **제1적구 일치 + 쿠션 순서(어느 레일을 어떤 순서로) 일치** → 그린 경로를 레일 순서로 변환해 비교, 위치 오차는 허용

### 선언 이득 후보 ❓
1. 가상포인트 보너스 (난이도 비례: 쿠션 수·샷 종류 배율)
2. 예측 판돈 몰수: "안 된다"에 건 사람들의 포인트를 선언 성공자가 가져감
3. 선언 성공 누적 → **찬스권** (예: 3회 성공 시 실패한 샷 1회 다시치기)
4. 선언 득점 = 1.5점 등 실제 점수 가산 (게임 밸런스 영향 큼)

### 마지막 쿠션 세션 (마무리) 확정
- 목표 점수 도달 → 바로 끝나지 않고 **마무리 샷 1회 성공** 필요
- 성공 조건: **수구의 첫 접촉이 반드시 쿠션(다이)** + 일반 3쿠션 조건 충족
  - 다이 1회 → 공 → … 3쿠션 성립: 성공
  - 다이 2회 → 공 → … : 성공
  - 다이 3회 이상 → 공 → … : 성공
  - 공부터 맞음: 득점 형태여도 **실패**
- 쿠션 수 집계(확정): 공 맞기 전 다이 횟수도 포함, 제2적구 접촉 전까지 합계 ≥3
- 실패 시 일반 실패처럼 턴 넘김, 다음 차례에 다시 마무리 시도
- 마무리 자격: **자기 약속 점수를 모두 채운 플레이어만** 마무리 단계에 진입
  - 점수가 남은 상태에서 다이 먼저 맞는 3쿠션 득점 = 그냥 일반 득점 1점 (경기 종료 아님)
  - 마무리 단계 플레이어가 공 먼저 맞는 일반 3쿠션 = 점수 없음, 실패 처리, 턴 넘김
- **마무리 단계 플레이어가 마무리 1회 성공 = 즉시 전체 경기 종료** (2·3위 결정용 추가 진행 없음)
- 2·3위 결정 (확정): ① 약속 점수 대비 **달성률(%)** 높은 순 → ② 동률이면 **애버리지(득점÷이닝)** 높은 순 → ③ 그래도 같으면 공동 순위
  - 마무리 단계에 진입했지만 성공 못한 사람 = 달성률 100%로 2위 확보
- 목표 점수를 채운 샷 직후, **같은 이닝에서 곧바로 마무리 시도** 가능 (확정)

## v0.9 순서 정하기 = 당구 상식 퀴즈 (확정)

### 기본
- 뱅킹 대신 **당구 상식 퀴즈** 득점 순으로 1·2·3번 순서 결정
- 3명 모두 **같은 문제**, 각자 시간 날 때 풂 → 3명 다 끝나면 결과·정답 동시 공개
- 공개 후 채팅으로 "그걸 틀리냐" 조롱 타임 (작은 정산 타임)

### 비동기 공정성 (검색 방지)
- 문항당 제한시간 (예: 15초), 시간 초과 = 오답
- 한 번 연 문제는 다시 못 봄, 풀다가 앱 나가면 그 문항 오답
- 다른 사람이 다 풀기 전까지 정답·남의 답 비공개
- 동점 처리: 정답 문항의 **총 응답시간 짧은 순** → 그래도 같으면 랜덤

### 문제 카테고리 (안)
- 규칙 (3쿠션 득점 조건, 파울 등)
- 용어 (한국 당구장 용어 / 정식 용어)
- 선수·대회 (PBA, LPBA, UMB 월드컵, 세계선수권)
- 역사·장비 (대대 규격, 공 지름·무게, 다이아몬드 시스템)
- 사진 퀴즈 (배치 보고 샷 종류 맞히기 — 게임 엔진으로 배치 이미지 생성 가능)

### 문제 출처 (확정)
- **제작자가 직접 작성한 약 100문항 문제 은행**
- 출제 로직: 경기마다 랜덤 추출, **전부 한 번씩 나올 때까지 중복 출제 없음** → 다 쓰면 다시 섞어서 반복
- 제작자는 구글 시트에서 문항 추가·수정 (코드 수정 없이 반영)
- 문항 형식: 번호 | 카테고리 | 문제 | 보기1~4 | 정답번호 | 해설(정답 공개 때 표시) | 사진(선택)
- 주의: 선수 키·나이처럼 출처마다 다르거나 변하는 정보는 오답 시비 위험 → 검증 가능한 사실 위주 출제
