# 당구 엔진 고도화 계획 (최우선 과제)

> 목표: 실제 당구장에서 치는 것과 근접한 물리·손맛. 멀티/재미요소는 엔진 완성 후.

## 1. 현재 엔진의 한계 (왜 단조로운가)
- 2D 근사 + 고정 마찰계수 + 단순 반사 → 상황별 미묘한 차이가 없음
- 공-공 충돌에 마찰 없음 → 스로(throw), 회전 전이 없음
- 쿠션이 "벽"으로 처리됨 → 실제 쿠션(공 중심보다 높은 지점 접촉, 압축·복원) 효과 없음
- 큐 기울기, 스쿼트(회전 줄 때 수구 밀림), 커브(맛세) 없음
- 효과를 숫자로 "과장"해 맞춘 아케이드식 보정 → 상황이 달라지면 어색해짐

## 2. 새 물리 모델 (문헌 기반, 3D)
| 영역 | 반영할 현상 | 근거 모델 |
|---|---|---|
| 공 상태 | 3축 회전, 미끄러짐/구름/제자리회전 상태 전이, 공 뜸(점프) | 강체 3D, 상태기반 해석해 + 이벤트 구동 |
| 천(클로스) | 미끄럼 마찰, 구름 저항, 수직축 회전 감쇠, 테이블 컨디션(빠른/느린 대) | Leckie–Greenspan, pooltool 계열 |
| 큐 타격 | 당점(좌우·상하), **큐 기울기**, 큐 무게, 미스큐 한계, **스쿼트**, **커브(스윙·맛세)** | Alciatore 측정 모델 |
| 공-공 | 반발계수, **공 사이 마찰 → 컷 스로·회전 스로**, 회전 일부 전이, 키스 | Alciatore throw 모델 (속도 의존 마찰) |
| 쿠션 | 공 중심보다 높은 접촉점(캐롬 쿠션 높이), 압축·복원 중 마찰, **속도 따라 달라지는 반사각**, 회전에 의한 꺾임, 쿠션 맞고 뜨는 현상(통통) | Mathavan et al. (2010) 쿠션 충돌 모델 |
| 공 규격 | 캐롬 공 61.5mm/210g, 대대 2.84×1.42m | UMB 규격 |

과장 보정 대신 **실제 물리량**으로 계산 → 상황이 다양해질수록 자연스럽게 다양한 결과.

## 3. 검증 기준 (실제 당구와 비교하는 시험)
- 구름 공 하프볼 → 수구 약 30° 꺾임 (30도 법칙)
- 스톱샷 / 밀어치기 / 끌어치기 거리가 실측 범위 내
- 컷 스로 최대 약 5°, 회전 스로 재현
- 최대 회전 시 스쿼트 1~2° 수준
- **다이아몬드 시스템(파이브앤하프 등)이 실제처럼 맞아떨어지는지** ← 핵심 판정
- 쿠션 반사각이 속도·회전에 따라 실제 경향대로 변하는지

## 4. 감각 (보고 듣고 치는 느낌)
- 3D 당구대: 큐 뒤 1인칭 시점 / 위에서 보기 전환, 확대
- 공 표면 무늬로 **회전이 눈에 보임**
- 충돌 세기에 따른 소리 (공-공 딱, 쿠션 퉁)
- 스트로크 입력: 큐를 당겼다 미는 제스처(속도=힘), 큐 기울기 조절
- 테이블 컨디션 랜덤/선택 (빠른 대, 무거운 대, 공 상태) → 매판 다른 느낌

## 5. 실험실 모드 (튜닝용)
- 공 위치 자유 배치, 같은 샷 반복, 초슬로우
- 공 속도·회전 벡터 실시간 표시, 궤적 겹쳐보기
- 물리 파라미터 실시간 조정 → 제작자가 "실제 느낌"에 맞춰 튜닝

## 6. 진행 단계
1. 물리 코어 재작성 + 자동 검증 시험
2. 실험실 모드 (2D 화면으로 먼저, 물리 확인용)
3. 3D 렌더링·카메라·소리
4. 스트로크 입력·큐 기울기
5. 제작자 반복 시험 → 튜닝 → 완성도 확보 후 멀티·재미요소
